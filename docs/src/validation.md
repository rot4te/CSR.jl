# Validation

## Test suite

`test/runtests.jl` (about 1000 checks, run on 1 and 4 threads) covers:

| File | Checks |
|---|---|
| `geometry_test.jl` | Survey conventions, chord spline, `dspline_len` and `path_excess` against quadrature, bend geometry. |
| `binning_test.jl` | Charge conservation, overlap weights, grid, Float32 grids, backend number types. |
| `wake_test.jl` | Source point on a circle (retardation residual, `ΔL`, angles, `I_csr` vs the circle and the steady-state kernel), exact vs small-angle path excess, first-bin integral, infinite drifts, V7. |
| `kick_test.jl` | Kick coefficient, steady-state kick in a long bend vs the analytic wake (< 2%), half kicks, dead particles, drift ≈ 0. |
| `kernels_test.jl` | Kernels against the serial reference implementation: grid, tables and source points exactly, kicks to 1e-12; Float32 and BigFloat particles. |
| `shielding_test.jl` | Image kick on a drift = uniform-motion field; hat-integrated table vs its analytic integral; free-space limit and shielding in a bend; averaged layer sum converges in the layer count. |
| `ad_test.jl` | `rrule` vs ForwardDiff `J'ȳ` (~1e-15) vs finite differences. |
| `slicing_test.jl` | Sliced tracking with CSR off reproduces unsliced tracking for every element kind. |
| `track_csr_test.jl`, `lcavity_test.jl` | `track_csr!` through Beamlines and Branches; SaganCavity slices vs the whole cavity (round-off). |
| `tps_test.jl`, `track_tps_test.jl` | TPS test particles in the frozen wake, for one kick and through `track_csr!` (Beamline, Branch with an lcavity): TPS Jacobian and second derivatives vs ForwardDiff of the same Float64 tracking (round-off; 1e-10 bound for the multithreaded deposit order); Float64 test particles follow bunch particles (≤ 1e-15). |

## Cross-check against Bmad/Tao

`crosscheck/` tracks identical initial particles (generated by Tao) through five lattices with Tao and with
`track_csr!` (`bmad_compat = true`). With BeamTracking 0.8.7 and Bmad 20260918.0, max |CSR.jl − Bmad| / max |Bmad|:

| Case | Per-step kick (free, shielded) | Final CSR Δpz (free, shielded) | `I_csr` from Bmad's orbit |
|---|---|---|---|
| Pure bend, on axis | 3.6e-7, 4.9e-7 | 4.1e-8, 7.8e-8 | — |
| Regression-test bend (`b1_gradient`, offset) | 1.1e-5, 9.3e-6 | 2.8e-6, 6.2e-6 | 2.8e-7 |
| Tao example (drifts, two combined-function bends) | 9.6e-6, 2.1e-4 | 3.6e-6, 5.1e-6 | 2.0e-6 |

Bmad's diagnostic output has 7 significant digits. The remaining end-to-end differences come from BeamTracking vs
Bmad tracking of combined-function bends; with Bmad's own orbit the CSR geometry and `I_csr` agree to ~1e-6.

## Accuracy checks of the default mode

- Steady-state kick vs the analytic wake: 2.0e-3 (n_bin 200) and 1.2e-3 (n_bin 400) of the peak.
- Image kernel vs an independent Liénard–Wiechert field with exact retardation on a circle: ≤ 3e-5 for source
  heights 3 cm – 1.9 m.
- Averaged image-layer sum vs 1024-layer brute force: ~1e-6 (32 layers), ~2e-7 (64 layers).
